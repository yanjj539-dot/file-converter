# 树洞情绪交互装置 - ESP32 技术文档

## 项目概述

基于 ESP32 的情绪交互装置，通过 FSR402B 触摸传感器、TTP223 触摸模块和 MPU6050 加速度计感知用户情绪，通过 WS2812 RGB LED 灯环和 DFPlayer Mini 提供视觉与听觉反馈。

## 硬件连接

### 引脚分配

| 模块 | ESP32 引脚 | 说明 |
|------|-----------|------|
| FSR402B 左 | A4 (GPIO32) | 力敏电阻模拟输入 |
| FSR402B 右 | A5 (GPIO33) | 力敏电阻模拟输入 |
| TTP223 | GPIO 4 | 电容触摸模块 |
| MPU6050 SDA | GPIO 16 | I2C 数据 |
| MPU6050 SCL | GPIO 17 | I2C 时钟 |
| WS2812 DIN | GPIO 2 | RGB 灯环数据 |
| SD卡 CS | GPIO 5 | 原生SPI 片选 |
| SD卡 SCK | GPIO 48 | 原生SPI 时钟 |
| SD卡 MOSI | GPIO 23 | 原生SPI 主机输出 |
| SD卡 MISO | GPIO 49 | 原生SPI 主机输入 |
| PAM8403 LIN | GPIO 25 | 音频左声道 (I2S DAC) |
| PAM8403 RIN | GPIO 26 | 音频右声道 |

## TTP223 触摸模块功能

| 操作 | 功能 |
|------|------|
| 短按 (< 2秒) | 切换音效开/关 |
| 长按 (> 2秒) | 切换自动模式/手动模式 |

### 模式说明

**自动模式**:
- 根据 FSR 压力值和 MPU6050 运动数据自动判断情绪
- 默认模式

**手动模式**:
- 通过 TTP223 短按循环切换情绪状态
- 情绪顺序: 疲惫 → 焦虑 → 愤怒 → 冷静

## 情绪判断逻辑

### FSR 压力值阈值 (ESP32 12位ADC: 0-4095)

| 状态 | FSR 值范围 | 情绪含义 |
|------|-----------|----------|
| 空闲 | 0-599 | 无触摸 |
| 轻触 | 600-1999 | 疲惫/低落 |
| 中按 | 2000-3499 | 焦虑/烦躁 |
| 重按 | ≥3500 | 愤怒/压抑 |

### MPU6050 运动幅度

| 状态 | 加速度变化 | 情绪含义 |
|------|-----------|----------|
| 冷静 | < 0.8 m/s² | 放松 |
| 焦虑 | 0.8-5.0 m/s² | 不安 |
| 愤怒 | > 5.0 m/s² | 激动 |

## 交互效果

| 情绪状态 | 灯光颜色 | 灯光效果 | 音效 |
|---------|---------|---------|------|
| 空闲待机 | 微弱蓝色呼吸 | 单灯微亮 | 无 |
| 疲惫/低落 | 冰蓝色 | 缓慢旋转呼吸 | 舒缓音乐 |
| 焦虑/烦躁 | 暖黄色 | 双向流水渐变 | 白噪音 |
| 愤怒/压抑 | 红色 | 快速爆闪+跑马灯 | 雷电音效 |
| 冷静放松 | 柔和绿色 | 轻柔呼吸 | 舒缓音乐 |
| 激动兴奋 | 彩虹色 | 快速变换 | 雷电音效 |

## 依赖库

通过 Arduino 库管理器安装：

- **Adafruit NeoPixel** - WS2812 灯环控制
- **Adafruit MPU6050** - MPU6050 传感器驱动
- **Adafruit Sensor** - 统一传感器接口

## 音效文件准备

DFPlayer Mini 需要在 SD 卡根目录放置音频文件：

```
SD:/
├── 0001.wav  (舒缓音乐)
├── 0002.wav  (白噪音)
└── 0003.wav  (雷电音效)
```

## 参数调整

可在代码中调整以下参数：

```cpp
#define THRESHOLD_LIGHT     600   // 轻触阈值
#define THRESHOLD_MEDIUM    2000  // 中按阈值
#define THRESHOLD_HEAVY     3500  // 重按阈值
#define MOTION_THRESHOLD_CALM    0.8   // 冷静运动阈值
#define MOTION_THRESHOLD_ANGRY   5.0   // 愤怒运动阈值
#define DEBOUNCE_MS         150   // 防抖时间(ms)
#define LONG_PRESS_MS       2000  // TTP223长按阈值(ms)
```
