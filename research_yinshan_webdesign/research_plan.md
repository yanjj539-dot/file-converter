# Research Plan: 隐山 (Hidden Mountain) Chinese Aromatherapy Brand Web Design

## Main Question
What specific CSS/JS effects, design patterns, and interactive elements are used in excellent Chinese-style websites, and which would work best for a Chinese aromatherapy brand page?

## Subtopics

### 1. Chinese-Style Website Examples & Design Patterns
Search for real-world examples: 新中式网页设计, 中国风网页效果, 水墨风网页, 禅意网页设计, 东方美学网站
- Find 3-5 excellent Chinese-style websites with URLs
- Extract design characteristics, color schemes, typography, layout patterns

### 2. CSS/JS Animation Effects & Code Implementations
Search for: CSS Chinese ink animation, CSS scroll painting reveal, ink wash effect CSS, 水墨动画CSS, 卷轴展开效果, 墨迹跟随
- Find actual CSS/JS code snippets for ink wash effects, scroll-triggered animations, Chinese painting parallax
- Look on CodePen, GitHub, and Chinese developer platforms (掘金, 思否) for implementations

### 3. Award-Winning Chinese Brand Websites Analysis
Research sites: 观夏 (To Summer), 闻献 (DOCUMENTS), 花西子 (Florasis), 故宫文创, 苏州博物馆
- Analyze their web design approach, interactive elements, and unique features
- Extract specific effects they use

### 4. Chinese Traditional Element Interactions & Typography
Search for: 云纹CSS, 回纹装饰, 竖排文字CSS, 书法字体动画, 印章效果CSS, 山水画parallax, 梅兰竹菊web设计
- Find implementations of traditional pattern decorations
- Typography effects for Chinese vertical text and calligraphy
- Interactive elements like seal stamps, scroll unfolding

## Expected Deliverables
- List of 5-8 specific CSS/JS effects with code snippets or implementation descriptions
- Recommendations for which effects suit a Chinese aromatherapy brand
- Source URLs
