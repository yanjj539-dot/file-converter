# 个人主页设计规格

**日期：** 2026-05-06  
**参考：** https://100t.xiaomimimo.com/

---

## 目标

制作一个风格与 Xiaomi MiMo Orbit 活动页相似的个人主页，单个 HTML 文件，无外部依赖，直接双击可打开。

---

## 技术栈

- 纯 HTML5 + CSS3 + 原生 JavaScript
- 零依赖，单文件
- 输出文件：`index.html`（放在项目根目录）

---

## 视觉风格

| 属性 | 值 |
|------|-----|
| 背景色 | `#0a0a0f` |
| 主色（紫蓝渐变） | `#6366f1` → `#8b5cf6` |
| 文字主色 | `#f8fafc` |
| 文字次色 | `#94a3b8` |
| 文字弱色 | `#64748b` |
| 边框 | `rgba(255,255,255,0.06)` |
| 高亮边框 | `rgba(99,102,241,0.3)` |

背景效果：CSS 网格线（40px × 40px，`rgba(99,102,241,0.05)`）+ 中心径向光晕渐变。

---

## 页面结构（从上到下）

### 1. 导航栏（固定顶部）

- 左：Logo 方块（紫蓝渐变）+ 姓名文字
- 右：关于 / 技能 / 联系 导航链接 + EN 语言标签
- 滚动后：`backdrop-filter: blur(12px)` 毛玻璃效果
- 高度：约 56px，`border-bottom: 1px solid rgba(255,255,255,0.06)`

### 2. Hero 首屏（100vh）

- 顶部小标签：`PORTFOLIO · 2026`，胶囊形，紫色描边
- 主标题：`Hi, I'm [姓名]`，姓名部分紫蓝渐变文字，末尾打字机光标 `_`（CSS 闪烁动画）
- 副标题：身份描述（如"设计师 · 开发者 · 创造者"）
- 简介文字：一两句话，`max-width: 480px`，居中
- CTA 按钮组：
  - 主按钮：紫蓝渐变背景，"联系我 →"
  - 次按钮：透明背景 + 细边框，"查看简历"
- 数字统计行：3 组数字（年经验 / 完成项目 / 创造热情），渐变数字，竖线分隔
- 打字机动效：JS 实现，循环打出多个身份词组，光标持续闪烁

### 3. 关于我 + 技能（两栏卡片）

- 两列等宽 Grid 布局
- 左卡片：`ABOUT ME` 标签 + 个人简介段落
- 右卡片：`SKILLS` 标签 + 技能标签云（胶囊形，紫色半透明背景）
- 卡片样式：`background: rgba(255,255,255,0.02)`，细边框，`border-radius: 10px`

### 4. FAQ 折叠区块

- 标题：`FAQ` 小标签
- 3 条问答，默认全部折叠
- 点击展开：CSS `max-height` transition 动画
- 展开状态：紫色描边 + 淡紫背景
- 折叠图标：`+` / `−` 切换

### 5. 底部 Footer

- 左：版权信息
- 右：GitHub / Twitter / Email 链接
- `border-top: 1px solid rgba(255,255,255,0.06)`

---

## 交互动效

| 效果 | 实现方式 |
|------|---------|
| 打字机 | JS 字符逐个追加，`setInterval`，循环多个词组 |
| 光标闪烁 | CSS `@keyframes blink`，`opacity` 0→1 循环 |
| FAQ 折叠 | CSS `max-height` transition，JS 切换 class |
| 导航毛玻璃 | `scroll` 事件监听，超过 60px 加 class |
| 按钮 hover | CSS `transform: translateY(-1px)` + `box-shadow` |
| 卡片 hover | `border-color` 过渡到紫色描边 |
